一、已解决的需求
============================================================

1. 批注卡片与原文同一行定位 ✅
   - AnnotationPanel 侧边栏的批注卡片通过 position: absolute 定位，
     与被批注文字保持同一 Y 坐标

2. 批注卡片布局（内容优先） ✅
   - 折叠状态: 原文引用（一行截断）+ 批注内容（两行截断）
   - 展开状态: 头像 + 用户名 + 角色标签 + 时间 + 完整内容 + 回复 + 删除
   - 角色颜色卡片左边框: 管理员红 / 上传者蓝 / 普通用户绿

3. 后端角色字段 ✅
   - CommentResponse.java 新增 role 字段

4. 删除批注无重复请求 ✅
   - AnnotationPanel 执行 DELETE API
   - ReadmeRenderer 只清理本地状态（removeLocalComment）

5. 新建批注位置不丢失 ✅
   - refreshAnnotations() 重新拉取后端完整数据

6. 被批注文本颜色高亮 ✅ 【核心修复】
   - 技术路线: CSS Custom Highlight API + 极简 DOM 边框层
   - 背景高亮 + 虚线下划线: 浏览器原生 ::highlight() 伪元素，零 DOM 开销
   - 左侧角色色条: 每个 annotation 创建 1 个 3px div（非每行 fragment 1 个）
   - recogito: 仅保留选区管理和事件系统，传入 no-op renderer 禁用其 DOM 渲染
   - 角色颜色: 管理员红(#e74c3c) / 上传者蓝(#3498db) / 普通用户绿(#27ae60)

   根因: useTextAnnotator.js 的 commentsToAnnotations() 生成的 W3C selector
   缺少 type 字段，recogito 的 qe() 解析器无法匹配 TextQuoteSelector/
   TextPositionSelector → 所有 annotation 被静默丢弃 → 零 DOM 元素 → 零高亮。

   改动文件:
   - composables/HighlightManager.js (新增) — CSS Custom Highlight API 封装
   - composables/BorderLayer.js (新增) — 极简 DOM 覆盖层（in-place 更新）
   - composables/useTextAnnotator.js (重写) — 修复 W3C selector + no-op renderer
   - components/article/ReadmeRenderer.vue (重构) — 集成新渲染管线
   - views/ArticlePage.vue — 提交/删除后 router.go(0) + sessionStorage 保持滚动
   - components/article/AnnotationPanel.vue — measureBodyOffset 修复 8px padding 偏移

7. 提交/删除后滚动位置保持 ✅
   - 操作完成后 router.go(0) 刷新页面
   - 刷新前 sessionStorage 保存 scrollY，加载后恢复

二、技术架构（批注渲染）
============================================================

文本批注库: @recogito/text-annotator（仅选区管理 + 事件）
渲染层: CSS Custom Highlight API（背景+下划线）+ 自定义 DOM（左边色条）
布局: flex 两列（README 内容 + 批注侧边栏）

渲染性能:
  操作          SPANS(旧)         当前方案
  加载 30 条    30-100+ span 创建  30 Range + 30 div
  选中/取消     全部重建           O(1) Highlight 优先级切换
  resize        全部重建           Highlight 零开销 + div 定位更新
  添加/删除     全部重建           O(1) Range + div
